# GOALS

## Problem and the end result from the user's point of view

Determine whether generic returned types can unify binding target, source scope and representation, with @This referring to that context.

## Measurable goals

Compile a prototype covering scoped and root functions, constructor roles, plugins, references, aliases and package placement; compare real-example declarations to the existing normalized output.

## Supported scope and non-goals

Research artifacts and isolated prototypes only. No public API replacement, example migration, release or push.

## Reference source / commit / license

## Completion criteria for the whole plan

A compiled prototype, reproducible checks, recommended public API and tradeoffs are documented and committed.
